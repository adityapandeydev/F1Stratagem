## 1. Raw Data Available from FastF1

### 1.1 Car Telemetry (per sample, ~3.7 Hz)
| Channel | Type | Unit | Description |
|---------|------|------|-------------|
| Speed | float | km/h | Car speed |
| RPM | float | — | Engine revolutions per minute |
| nGear | int | — | Current gear (0-8, 0 = neutral) |
| Throttle | float | % | Throttle pedal pressure (0-100) |
| Brake | bool | — | Brakes applied or not |
| DRS | int | — | DRS status (0=off, 1=eligible, 8=detected, 10-14=active) |
| Time | timedelta | — | Time since start of data slice |
| SessionTime | timedelta | — | Time since session start |
| Date | datetime | — | Absolute timestamp of sample |
| Source | str | — | 'car', 'pos', or 'interpolated' |

### 1.2 Position Data (per sample)
| Channel | Type | Unit | Description |
|---------|------|------|-------------|
| X | float | 1/10 m | X coordinate on track |
| Y | float | 1/10 m | Y coordinate on track |
| Z | float | 1/10 m | Z coordinate (elevation) |
| Status | str | — | 'OnTrack' or 'OffTrack' |

### 1.3 Computed Telemetry Channels (FastF1 built-in)
| Channel | Method | Description |
|---------|--------|-------------|
| Distance | `add_distance()` | Cumulative distance driven since first sample |
| DifferentialDistance | `add_differential_distance()` | Distance between consecutive samples |
| RelativeDistance | `add_relative_distance()` | Normalized track position (0.0 to 1.0) |
| DriverAhead | `add_driver_ahead()` | Car number of driver ahead |
| DistanceToDriverAhead | `add_driver_ahead()` | Gap to driver ahead in meters |

## 2. Derived / Computed Metrics

These are NOT directly available from FastF1 — we compute them from raw data.

### 2.1 Speed Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Top speed per lap | max(Speed) for each lap | Straight-line performance |
| Minimum corner speed | min(Speed) within corner boundaries | Cornering confidence |
| Average speed per lap | mean(Speed) | Overall pace |
| Speed at each corner entry | Speed at defined braking point | Braking analysis |
| Speed at each corner apex | Speed at minimum-speed point | Cornering technique |
| Speed at each corner exit | Speed at throttle resumption | Traction analysis |
| Speed differential (vs opponent) | Speed_A - Speed_B at each distance point | Direct comparison |
| Speed advantage zones | Where driver is consistently faster | Track dominance map |
| DRS effectiveness | Speed delta with DRS active vs without | Straight-line gain from DRS |
| Sector speeds | Average speed per sector | Sector performance |

### 2.2 Braking Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Braking point distance | Distance at which Brake transitions to true | Late braking analysis |
| Braking zone length | Distance from brake-on to brake-off | Braking aggression |
| Braking point comparison | Delta between two drivers' braking points | Head-to-head technique |
| Brake application duration | Time spent braking per corner | Braking confidence |
| Trail braking detection | Brake still applied while turning | Advanced technique analysis |
| Braking stability | Variance in braking points across laps | Consistency analysis |

### 2.3 Throttle Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Full throttle percentage | % of lap at 100% throttle | Power circuit indicator |
| Throttle application point | Distance at which throttle exceeds threshold post-corner | Traction confidence |
| Time to full throttle | Time from corner exit to 100% | Traction performance |
| Throttle modulation | Variance in throttle % through corners | Smoothness vs aggression |
| Lift-and-coast detection | Throttle < 100% on straights before braking | Fuel/energy management |
| Coasting distance | Distance of lift-and-coast per lap | Energy management |
| Partial throttle zones | Regions where throttle is between 20-80% | Car balance indicator |

### 2.4 Gear Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Gear at each corner | Gear number at corner apex | Corner classification |
| Gear shifts per lap | Count of gear changes | Lap complexity |
| Upshift RPM | RPM at each upshift point | Engine usage |
| Downshift points | Distance of downshifts relative to corners | Technique comparison |

### 2.5 Time Delta Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Cumulative time delta | Running time difference between two drivers' laps | Gap evolution |
| Sector time delta | Sector time difference | Where time is gained/lost |
| Mini-sector time delta | Time difference at N equally-spaced track segments | Granular advantage map |
| Corner-by-corner delta | Time gained/lost at each corner | Detailed technique comparison |
| Gap to leader (per lap) | Cumulative time behind leader | Race gap evolution |
| Gap to driver ahead | Time delta to car in front | Battle tracking |
| Interval (lap-by-lap) | Gap change between consecutive laps | Closing/pulling away |

### 2.6 Lap Consistency Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Lap time standard deviation | σ(LapTime) across stint | Consistency rating |
| Lap time coefficient of variation | σ/μ of lap times | Normalized consistency |
| Fastest vs average delta | FastestLap - AvgLap | Peak performance reserve |
| Degradation rate | Slope of lap times over stint | Tyre degradation |
| Clean air pace | Avg pace when gap to ahead > 3s | True race pace |
| Dirty air pace | Avg pace when gap to ahead < 2s | Following performance |
| Safety car restart pace | First 3 laps after SC restart | Restart performance |

### 2.7 Pit Stop Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Pit stop duration | PitInTime to PitOutTime | Pit crew performance |
| Pit stop time loss | Lap time with pit vs average lap | Total pit cost |
| Pit lane time | Time in pit lane | Speed limit compliance |
| Undercut effectiveness | Position gained/lost via early stop | Strategy analysis |
| Overcut effectiveness | Position gained/lost via late stop | Strategy analysis |
| Pit stop count | Total number of stops | Strategy profile |

### 2.8 Position Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Positions gained/lost on lap 1 | Grid position vs position after lap 1 | Start performance |
| Positions gained total | Grid position vs finish position | Race craft |
| Position changes per lap | Delta in position each lap | Overtaking/defending |
| Laps in position | Count of laps spent in each position | Position stability |
| Laps led | Laps in P1 | Dominance |
| Overtakes made | Position improvements (filtered for pit stops) | Racecraft |
| Defensive laps | Laps where attacked but maintained position | Defensive skill |

### 2.9 Racing Line Metrics
| Metric | How Computed | Use Case |
|--------|-------------|----------|
| Racing line overlay | X, Y path of the car | Technique visualization |
| Racing line divergence | Distance between two drivers' paths | Line choice comparison |
| Track limits violations | Status == 'OffTrack' detections | Aggression indicator |
| Apex clipping distance | Closest approach to geometric apex | Precision metric |

## 3. Individual Session Views

Everything a user can see for a SINGLE session (not comparison).

### 3.1 Session Overview Dashboard
- Session info (date, circuit, weather summary)
- Results table (position, driver, team, time/gap, grid position, points)
- Fastest lap highlight
- Track conditions summary (dry/wet, temperature range)
- Key events timeline (safety cars, red flags, notable incidents)
- Weather evolution chart (temperature + rainfall over time)

### 3.2 All Drivers — Lap Time Chart
- **Lap time scatter plot** — every driver's lap time, each lap, color-coded by compound
- **Box plot** — lap time distribution per driver (show median, quartiles, outliers)
- **Violin plot** — lap time density distribution per driver
- Filters: exclude pit laps, exclude SC laps, compound filter, driver filter

### 3.3 All Drivers — Race Pace Ranking
- Average race pace per driver (excluding pit laps, SC laps, first lap)
- Pace delta to leader
- Pace by compound
- Pace by stint
- Pace percentile ranking

### 3.4 All Drivers — Speed Trap Data
- Speed trap ranking (highest to lowest)
- Finish line speed ranking
- Intermediate speed comparisons
- Speed trap speed by lap (evolution)

### 3.5 Single Driver — Lap Detail View
- Every lap time listed with sector times, compound, tyre life, position
- Lap time trend chart (with compound color bands)
- Sector time evolution chart
- Speed trap evolution
- Personal best indicators
- Deleted lap annotations

### 3.6 Single Driver — Telemetry View (Single Lap)
- Speed trace vs distance
- Throttle trace vs distance
- Brake trace vs distance
- RPM trace vs distance
- Gear trace vs distance
- DRS status vs distance
- All synchronized on the same distance axis with linked zoom/pan

### 3.7 Session — Tyre Strategy Overview
- Horizontal bar chart showing each driver's stint compounds and lengths
- Compound usage distribution (how many laps on each compound)
- First stint compound distribution (grid strategy)
- Pit stop timing chart (which lap each driver pitted)

### 3.8 Session — Weather Timeline
- Air temperature vs time
- Track temperature vs time
- Humidity vs time
- Wind speed & direction vs time
- Rainfall indicator overlay
- Correlation with track status (SC, red flag)

### 3.9 Session — Track Status Timeline
- Visual timeline: green → yellow → SC → VSC → red flag
- Duration of each status period
- Lap range of each status period
- Race control messages overlay

## 4. Driver vs Driver Comparison

The core comparison feature. Users select 2 (or more) drivers and get deep analysis.

### 4.1 Telemetry Overlay (Same Lap)
- Speed overlay (both drivers on same chart)
- Throttle overlay
- Brake overlay
- RPM overlay
- Gear overlay
- DRS overlay
- All vs distance with synchronized zoom/pan
- **Cumulative time delta chart** — shows running time difference

### 4.2 Lap Selection Options
| Selection Mode | Description |
|----------------|-------------|
| Fastest lap | Compare each driver's fastest lap of the session |
| Best qualifying lap | Q1/Q2/Q3 fastest |
| Specific lap number | Compare lap N for both drivers |
| Average lap | Composite of all clean laps |
| Fastest sector combination | Theoretical best (best S1 + best S2 + best S3) |
| Selected stint | Compare specific stint |
| Custom lap range | Compare average across lap X-Y |

### 4.3 Sector Comparison
- Sector 1/2/3 time comparison (bar chart)
- Sector delta (who is faster in each sector, by how much)
- Mini-sector breakdown (10-20 equal segments per lap)
- **Sector dominance chart** — heatmap showing which driver wins each mini-sector

### 4.4 Corner-by-Corner Analysis
For each corner on the circuit:
- Entry speed comparison
- Apex/minimum speed comparison
- Exit speed comparison
- Braking point comparison (who brakes later/earlier)
- Throttle application point comparison
- Time gained/lost at each corner
- Gear used at apex
- Corner classification (low/medium/high speed)

### 4.5 Speed Comparison
- Top speed comparison per lap
- Speed trap comparison
- Speed advantage map (which track segments each driver is faster)
- Speed differential chart vs distance

### 4.6 Braking Comparison
- Braking point overlay (distance markers on track map)
- Braking zone length comparison
- Trail braking comparison

### 4.7 Throttle Comparison
- Full-throttle percentage comparison
- Throttle application comparison post-corner
- Lift-and-coast comparison
- Throttle modulation comparison

### 4.8 Racing Line Comparison
- Track map with both drivers' racing lines overlaid
- Racing line divergence heatmap
- Corner-by-corner line choice visualization

### 4.9 Race Pace Comparison
- Lap time overlay (both drivers across all race laps)
- Stint-by-stint pace comparison
- Clean air pace comparison
- Dirty air pace comparison
- Degradation rate comparison per stint
- Gap evolution chart (running gap between two drivers)

### 4.10 Tyre Strategy Comparison
- Side-by-side stint visualization
- Compound choice comparison
- Stint length comparison
- Degradation comparison on same compound
- Pit stop timing comparison

### 4.11 Teammate Comparison (Special Mode)
Everything in 4.1-4.10 but specifically framed for teammates:
- Qualifying H2H record
- Race H2H record
- Average qualifying delta
- Average race pace delta
- Teammate gap evolution across season
- Points comparison

## 14. Track Map Visualizations

All track visualizations use X, Y, Z position data. The Z coordinate provides **real track elevation**, making F1Stratagem the only platform that renders circuits in true 3D.

### 14.0 — SIGNATURE: 3D Elevated Track with Dual-Aura Glow Comparison

The flagship visualization. Built with Three.js / React Three Fiber.

**Base Layer — 3D Elevated Track:**
- The circuit is rendered as a 3D ribbon that follows real elevation from FastF1's Z-coordinate data
- Spa: Eau Rouge/Raidillon visibly climbs, the descent to Pouhon drops away
- COTA: Turn 1 hill rises dramatically out of the landscape
- Interlagos: Senna S dips and rolls
- Monaco: tunnel section descends, the climb to Casino is visible
- Every circuit feels REAL — users understand the track's character at a glance
- The track can be orbited, rotated, zoomed (interactive 3D camera controls)
- Corner numbers labeled at each turn

**Comparison Layer — Dual-Aura Glow:**
- The 3D track ribbon stays neutral/dark as the base
- Two neon glow auras radiate outward from each side of the track
- Driver A's glow radiates to the left, Driver B's to the right
- Where a driver is faster, their glow WIDENS and INTENSIFIES
- Where they're equal, both sides glow evenly
- The glow casts light onto the ground below the elevated track — when Eau Rouge rises, the winning driver's light spills downward dramatically
- Intensity maps to time delta magnitude (bigger advantage = brighter, wider glow)

**Animation:**
- The comparison animates around the track with playback controls (play/pause, 0.5x/1x/2x)
- Running gap counter updates live below the track
- Speed delta bar shows instantaneous speed difference
- Scrub to any point on the track to inspect that section

**Standalone Elevation View (no comparison):**
- View any circuit's 3D elevation profile on its own
- Overlay speed as a color gradient on the elevation ribbon — see where cars accelerate uphill/downhill
- Overlay gear as color — shows downshifts before uphill corners, high-gear crests
- Useful as a Circuit Intelligence feature (§13)

### 14.1 Speed Heatmap
- Track map colored by speed (blue=slow → red=fast)
- Available in both 2D flat and 3D elevated views
- Compare two drivers' speed heatmaps side-by-side

### 14.2 Gear Map
- Track map colored by gear number
- Shows where each gear is used
- 3D elevated version shows gear changes relative to elevation

### 14.3 Throttle/Brake Map
- Track map showing throttle and brake zones
- Green = full throttle, red = braking, yellow = partial throttle
- 3D version: see braking zones relative to downhill/uphill sections

### 14.4 Time Gained/Lost Map
- Track map showing where Driver A gains/loses time vs Driver B
- Green = gaining, red = losing, intensity = magnitude
- 3D version uses the dual-aura glow for this

### 14.5 Racing Line Overlay
- Both drivers' racing lines superimposed on track map
- Highlight divergence zones
- 3D version: see line choice relative to elevation (late apex on uphill, early apex on downhill)

### 14.6 Speed Differential Map
- Track map colored by speed difference (A faster vs B faster)

### 14.7 DRS Zone Map

## 16. F1Stratagem Original Ideas

Features not commonly found on existing platforms.

### 16.1 "What If" Lap Constructor
- Users select best S1 from driver A, best S2 from driver B, best S3 from driver C
- System constructs a "theoretical best lap" with telemetry
- Compare theoretical best vs actual best
- Shows what a "perfect lap" would look like

### 16.2 Telemetry Replay
- Animated replay on the **3D elevated track** (§14.0) — not flat dots
- Two glowing car markers race around the real-elevation circuit
- Each car trails a fading ribbon in its team color, showing the path just driven
- The dual-aura glow builds progressively as the replay advances
- Synchronized speed/throttle/brake/gear gauges animate alongside
- Running gap counter + speed delta bar update live
- Playback controls: play/pause, 0.5x/1x/2x speed, scrub timeline
- Camera: auto-follow, free orbit, or fixed-angle views
- Mini-map in corner shows full circuit with car positions

### 16.3 Corner Mastery Ranking
- Rank all drivers by performance at each specific corner
- "Who is the best at Turn 1 at Bahrain?"
- Aggregate across sessions and seasons

### 16.4 Adaptability Score
- How quickly a driver adapts to:
  - New circuits
  - Changing conditions
  - Car updates
  - Different tyre compounds
- Measured by improvement rate across sessions

### 16.5 Driving Style Fingerprint
- Unique visualization of a driver's style
- Based on: braking aggression, throttle smoothness, corner speed, line choice
- Comparison: "Show me drivers with similar styles to Verstappen"

### 16.6 Circuit DNA Match
- Which circuits suit which drivers/cars
- "This circuit is 78% similar to Suzuka" based on corner types, speed profile
- Predict performance at new circuits based on similar circuit performance

### 16.7 Pressure Index
- Real-time-derived metric for how much pressure a driver is under
- Inputs: gap to car behind, championship position, recent incidents, weather
- Historical: how drivers perform under varying pressure levels

### 16.8 Energy Management Visualization
- Lift-and-coast detection and visualization
- Estimated energy deployment patterns
- Comparison of energy management styles

### 16.9 Race Momentum Tracker
- Composite metric tracking a driver's "momentum" through a race
- Combines: pace trend, position changes, gap changes, tyre condition
- Shows when a driver is "in the zone" vs struggling

### 16.10 Battle Analyzer
- Automatically detect wheel-to-wheel battles
- Show close-proximity laps
- Analyze attack/defend patterns
- DRS usage in battles
- Outcome tracking (overtake success rate)

### 16.11 Season Form Curve
- Rolling average performance metric across the season
- Shows hot streaks and cold spells
- Correlate with external factors (upgrades, driver changes)

### 16.12 "Career Timeline" View
- Full career visualization for a driver
- Teams, results, key moments, championship positions
- Performance trend across entire career
- Interactive timeline with drill-down

### 16.13 Team Order Detection
- Identify probable team orders
- Compare pace pre/post position swap
- Lap time differential when one driver is "holding position"

### 16.14 Grid Penalty Impact Analysis
- How much does a 5/10/20-place grid penalty actually cost?
- Recovery rate from penalty positions
- Driver-specific recovery ability

### 16.15 Fuel-Corrected Practice Pace
- Estimate fuel load from lap times
- Normalize practice times to equal fuel load
- More accurate practice pace comparison

### 16.16 Tyre Cliff Predictor
- Using historical degradation data
- Predict when each driver will hit tyre cliff
- Alert window for optimal pit timing

### 16.17 Session Comparison Matrix
- Compare any session to any other session
- FP1 vs FP2, FP3 vs Qualifying, Practice vs Race
- Track evolution quantification
- Pace improvement between sessions

### 16.18 Multi-Driver Comparison (3+ Drivers)
- Not just 1v1 — compare 3, 4, 5+ drivers simultaneously
- Telemetry overlay with N drivers
- Ranking table across all metrics
- Team-level aggregate comparisons

### 16.19 Historical "Who Would Win" Simulator
- Place two drivers from different eras at the same circuit
- Normalize for car performance using era-relative data
- Probabilistic outcome based on available data
- Heavy caveats and confidence intervals displayed

### 16.20 Automated Insights
- After viewing any page, system generates text insights
- "Hamilton was 0.2s faster in Sector 1 due to a later braking point into Turn 1"

- Based on rule-based analysis of the displayed data
